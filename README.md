# 投研信息整理小工具

把投研日常里的"找资料、理信息、写摘要"变成**一句话就能触发**的工具。

输入一段（或一批）公开报道文本，输出**结构化的融资事件表**，并可以推送到飞书群。

> 为什么做这个：投资团队每天都在搜集行业信息、整理项目资料、写摘要。
> 这件事的重复度很高，但字段口径又必须统一——正好适合用大模型 + 一层结构化约束来做。

## 抽取字段

| 字段 | 说明 |
|---|---|
| company | 公司名 |
| industry | 所属行业 |
| round | 轮次（天使轮 / A 轮 / B 轮 …） |
| amount | 金额，**保留原文**（"数千万人民币""近亿元""未披露"） |
| investors | 投资方 |
| date | 披露日期 |
| source | 来源（链接或媒体名） |

## 怎么跑

```bash
# 1）不调模型，先验证流程能跑通（规则模式，用于冒烟测试）
python main.py "智能驾驶" --offline

# 2）调大模型：先设置环境变量
#    PowerShell:
#      $env:LLM_API_KEY="你的key"
#      $env:LLM_BASE_URL="https://api.deepseek.com/v1"   # 任何 OpenAI 兼容接口
#      $env:LLM_MODEL="deepseek-chat"
python main.py "智能驾驶" --input sample_input.txt

# 3）把结果推到飞书群
#    飞书群 → 群设置 → 群机器人 → 添加机器人 → 自定义机器人 → 复制 webhook
#      $env:FEISHU_WEBHOOK="https://open.feishu.cn/open-apis/bot/v2/hook/xxxx"
python main.py "智能驾驶" --feishu
```

输出：`output.csv`（UTF-8-BOM，Excel 直接打开不乱码）。

命令行参数：`--text "一段文本"` 可直接传文本；`--out 路径` 指定输出文件。

## 两种模式（重要）

- **模型模式**（默认，需要 `LLM_API_KEY`）：把文本交给大模型，要求它**只输出 JSON**，代码侧做围栏剥离与容错解析。金额保留原文，不做单位换算——避免自作聪明地算错。
- **规则模式**（`--offline`）：用正则匹配"公司 + 轮次 + 金额"。**只用来验证流程能否跑通**，抽取质量明显低于模型模式，不要拿它当真实能力。

## 效果

- 7 个字段可稳定输出为 CSV；示例输入 3 条事件全部命中（含"未披露""数千万人民币""近亿元"三种金额写法）。
- 金额一律保留原文，不做换算——这是刻意的设计：**宁可留给人判断，也不要在数据里埋一个算错的数。**

## 已知失败情况

| 情况 | 表现 | 当前处理 |
|---|---|---|
| 一条报道里混了多轮融资 | 可能只抽到主要那轮 | 模型模式下要求输出数组，但**同一家公司多轮次时仍需人工核对** |
| "投资方"是一长串机构名 | 边界容易切错 | 保留原文，不强行拆分 |
| 金额用"未透露/不祥"等非标准说法 | 抽不到 | 返回 null，不猜 |
| 规则模式下复杂句式 | 公司名带前缀 | 只当冒烟测试用 |

## 局限与下一步

- 目前只做**文本 → 结构化表**，没有做来源抓取（爬取）与去重
- 下一步：加数据来源白名单、按"公司 + 轮次 + 时间"去重、把结果写入飞书多维表格

## 声明

本项目**只使用公开信息**，不涉及任何机构的内部数据；示例输入中的公司名均为占位示例。
